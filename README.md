# InpaintAR

This project contains the Unity Project and the LaTeX Thesis of my Bachelors Thesis about Inpainting Methods in Realtime for XR.

The prototype implemented for this thesis has the following features:

- [x] Hand Gesture Tracking and detection
- [x] When Rectangle is detected, use raycasts to get boundaries of selected area
- [x] Overlay Mask to fill boundaries
- [x] Fill Mask through inpainting
